# SAMURAI RUSH — 爽快剣戟アクション

横スクロール3D（Three.js）の侍アクション。**斬る・弾く・駆け抜ける**の3つで敵の群れを一刀両断します。

## 遊び方
| 操作 | キー | パッド |
|---|---|---|
| 移動 | A / D | 左スティック |
| ジャンプ（空中でもう1回） | SPACE | A |
| 斬る（連打で3連撃） | J / 左クリック | X |
| 斬り上げ（浮かせる） | W + J | ↑ + X |
| 落下斬り | 空中で S + J | 空中で ↓ + X |
| パリィ | K / 右クリック | B |
| 燕返し（駆け抜け斬り） | SHIFT | RB / RT |
| 居合・奥義 | I | Y |
| ポーズ | ESC / P | START |

- **燕返し**：斬気を1消費。通り道の敵に印を付け、駆け抜けた瞬間に**全員を同時に真っ二つ**。斬気が空でも短い回避ステップは出せる。
- **居合**：斬気2消費。溜めて前方11mを一閃。
- **パリィ**：敵の攻撃の直前に押すと完全弾き。怯んだ敵は一撃で成敗。矢は跳ね返せる。
- 敵の頭上の **青い「!」＝弾ける**、**赤い「!!」＝弾けない（燕返しで避ける／跳ぶ）**、**黄の矢印＝飛び道具**。
- ギリギリで避けると「見切り」でスローモーション。
- 戦いの場は敵を全滅させると開く。各幕の後に**巻物**（強化）を1つ選ぶ。全4幕＋**百人斬り**（エンドレス）。

## 開発
```
npm install
npm run dev
npm test             # ロジックはUIから分離し Vitest で検証
npm run build        # dist/        … itch.io 用
npm run build:local  # dist-local/index.html … 単一HTML（ダブルクリックで起動）
```
- `src/samurai/` … 描画から独立した戦闘シミュレーション（`World`）とデータ
- `src/render/` … Three.js 描画（手続き生成のキャラ `Rig`、ステージ、斬撃エフェクト、真っ二つ演出）
- `src/game/` … 入力・HUD・演出・メニュー
- 画像/音声アセットは使わず、Canvas生成テクスチャとWebAudio合成音のみ。音は最初のクリック/キー入力後に有効化。
