# ストーリーの因果（手がかりの連鎖）

「なぜ、そこへ行くのか」「なぜ、それを知っているのか」を、プレイヤーが辿れるようにするための設計メモ。
情報（fact）は **必ず、どこかで見聞きして** 手に入れる。知らないことは話せない・聞けない。

## 1. 駅の謎（黒田）

```
[LOOP1] 田所に最近の噂を聞く ─→ 「駅は15時で閉まるらしい」(station_rumor)
   │                                  └ 黒田に「閉まるんですか？」と聞ける（噂を聞いた後だけ）→「いつも通り」(嘘)
   └→ 14:50 に駅で確かめる ─→ 黒田が15:00に閉めて倉庫へ消える (station_3pm)
        └→ 倉庫に入る ─→ 黒田はいない。床に継ぎ目 (warehouse_empty)
[LOOP2〜] 14:45 の駅で、町長と黒田の密談を盗み聞き (kuroda_shiina_talk)「地下の件は、今日で最後にしてくれ」
        黒田を尾行 ─→ 倉庫の床扉に降りるのを見る (hatch_known)
        ミナに噂を伝える ─→ ミナが駅で黒田に詰め寄る ─→ 黒田が鍵をくれる (key_basement)
        　（継ぎ目を見た後でないと「持ち上げてみろ」は起きない）
```

## 2. 町長と神社の扉

```
密談の「地下の件」(kuroda_shiina_talk) ─→ 朝霧に町長のことを尋ねる ─→「毎晩22時に本殿の裏へ」(shiina_night_visit)
   └→ 22:00 に石段の陰から町長を見張る ─→ 石の扉(shrine_hatch) ─→ 地下施設へ
```

## 3. 病衣の男

```
19:20 診察室を覗く ─→ 佐伯が空の椅子に「今夜も、20時には駅へ行くんだね」(saeki_empty_patient)
   ├→ 20:00 の駅に病衣の人影 (patient_station_2000)
   └→ 診療所の控え：18:00に死亡した患者 (cert_18)・カルテ (chart_self)
cert_18 + patient_station_2000 を「つなげる」─→ 死者が駅にいる (patient_paradox)
   └→ 20:00 の駅で人影を確かめる ─→ 自分自身。リストバンド 000817 (self_patient, door_code)
```

## 4. 地下施設

```
広間：記憶カプセル＋六桁のテンキーの扉 (capsules, control_door)
   └→ 000817 で扉を開ける ─→ LOOP 412907 (loop_count_huge) ─→ 妹・凛 (truth_sister) ─→ 自分の正体 (truth_self) ─→ 栞 (truth_girl)
```

## 5. ループの確信

LOOP2 の朝、ミナが昨日とまったく同じ台詞で訪ねてくる ─→ 「本当にループしている」(loop_confirmed)。

## 6. 周回の「今日の焦点」

焦点の手がかり（`THREADS`）は、**その時点で持っている情報**に応じて、次の一手を示す。
前提の情報が無い手がかりは出ない（例：「噂」を聞く前は「14:50に駅へ」とは言わない）。
