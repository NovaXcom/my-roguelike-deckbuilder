# 画像素材 仕様書（『最後の一日』 現行版）

現在の実装（歩き回り探索＋追跡・隠れるアクション）に合わせた、**今必要な画像素材**の一覧。
現状は全ての絵を Canvas の手続き描画で代用している（`src/ui/render.ts`）。素材が無い場合は従来描画にフォールバックする方針なので、**納品できたものから順に差し替えられる**。

## 0. 共通方針

- 画風：ノスタルジックなドット絵（または淡い色調のイラスト）。夏の海沿いの町、強い光と濃い影。
- 基準解像度：**320×180**（16:9）。ドット絵は 1px = 1ドットで描き、表示は整数倍の最近傍拡大。
- 形式：PNG（透過）。単一HTML化するため**全素材の合計 10MB 以内**を目安（上限20MB）。
- 色味：背景・キャラは**昼の光（白色光）基準**で描く。朝夕夜の色・停電・光の柱・亀裂はコードが重ねる。
- **背景・キャラに文字を描かない**（看板・時計の文字盤は無地。「コンビニ」「花」等はコードで重ねる）。
- 命名：小文字英数字とアンダースコア。下表のファイル名で納品。

## 12. コード側の対応（素材納品後に実装）

- 背景・スプライト・立ち絵・CG・小道具を `Image` で読み込み、未納品／読み込み失敗なら**現行の手続き描画にフォールバック**。
- 立ち絵は台詞の話者名から自動選択（表情はスクリプトに `expr` を追加）。
- スプライトシートは「待機2・歩行4・しゃがみ1」の並びで読み込み、移動中は歩行コマ、物陰で立ち止まると主人公はしゃがみコマに切替。
- 単一HTML化では画像を base64 で埋め込む（`assetsInlineLimit` 設定済み）。10MBを超えそうなら WebP 化。
- 時刻の色味・停電・光の柱・亀裂・視界の扇形の着色は従来どおりコードで重ねる。
