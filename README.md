# 最後の一日

**2D探索アドベンチャー × タイムループ × ミステリー**

海沿いの小さな町「アステル」。8月17日 8:00 に目覚め、23:59 に世界が終わり、また 8:00 に戻る。
前の周回で「何を知ったか」だけでなく、**「誰に何を伝えたか」** が、次の一日を変えていく。

## 遊び方

| 操作 | 内容 |
|---|---|
| WASD / 矢印キー / クリック | 町を歩く（クリックした場所へ移動） |
| E（Space / Enter） | 近くの人に話す・光る印の場所を調べる |
| 画面の左右の端へ歩く | 隣の場所へ移動（行き先が複数なら選ぶ。10〜30分かかる） |
| 🗣 伝える | 居合わせた人に、知っていること（や噂）を話す。**伝えた内容は次の周回にも残る** |
| 📓 記憶（M） | 証拠ボード。カードを2枚選んで「つなげる」と推理できる |
| ⏱ 時間の流れ | **時計はリアルタイムで進む**（止める／ゆっくり／ふつう／はやい）。住民は行動表どおりに歩いて現れ、去っていく |
| 💡 ヒント | 今の焦点に沿った手がかり |

- **追跡・隠れる**：🕵 マークの場所では、動いている住民（町長・ミナ・黒田）に気づかれないよう忍び寄る。対象は一定間隔で**「？」の予告のあと振り返る**。物陰（暗い箱）で**立ち止まれば隠れられる**。見つかり続けると失敗するが、時間を少し失うだけで再挑戦できる（失敗するほど判定が甘くなる）。苦手な人向けに、メニューで「かんたん（自動成功）」にもできる。
- 「14:50の駅」「17:30の海岸」のような時間窓は、**その時間にその場所にいる**ことで発生する。調べられる場所には光る印が出る。

- 周回の初めに「今日は何を変える？」と焦点を選ぶ。選んだ焦点の次の一手がパネルに表示される。
- 取り返しのつかない失敗はない。何も掴めなかった周回でも、必ず少女が手がかりを一つ残す。
- 住民との関係（♥）は周回するほど深まり、深まった先で「記憶」を受け取れる。エンディングは4種類。

## 開発

```bash
npm install
npm run dev          # 開発サーバ
npm test             # Vitest（ロジック・攻略ルート・データ整合性）
npm run build        # dist/        … itch.io 等のWeb公開用
npm run build:local  # dist-local/index.html … 全アセット埋め込みの単一HTML（ダブルクリックで起動）
```

単一HTMLは約130KB（上限20MB）。画像・音声ファイルは使わず、Canvas の手続き描画と WebAudio 合成音で動作する。
AudioContext は、タイトル画面で最初にクリックされるまで開始しない（Autoplay対策）。

### 画像素材

`src/assets/` の PNG（背景・キャラのスプライトシート・タイトル・ロゴ・favicon）を読み込んで描画する（ビルド時に埋め込み、単一HTMLでも動作）。
素材が無い・読み込めない場合は、Canvas の手続き描画に自動でフォールバックする。素材の仕様と納品状況は `docs/ART_ASSETS.md`。
`store/` は itch.io のページ用画像（カバー・バナー）で、ゲームには含まれない。

### 構成

```
src/engine/   ゲームロジック（UI非依存）
  logic.ts      条件評価 / NPCの行動表 / 利用可能な行動 / 移動 / 「伝える」 / 推理
  runner.ts     シナリオ(ジェネレータ)の実行。効果（情報・フラグ・好感度・時間）の適用
  session.ts    行動 → 時間経過 → 自動イベント → 23:59 の進行
  state.ts      状態・周回リセット・セーブ
src/data/     シナリオ・データ（ここを書き足せば内容が増える）
  world.ts      場所 / 住民12人の1日の行動表
  facts.ts      「記憶」ボードの情報 / 推理の組み合わせ / 周回ごとの焦点
  events_*.ts   会話・調査・自動イベント・最終局面
  tells.ts      「誰に何を伝えたか」への反応
  endings.ts    エンディング
src/ui/       Canvas描画 / WebAudio / DOM UI
tests/        Vitest
```

### シナリオの書き方

イベントは「条件 + 所要時間 + スクリプト」のデータ。例：

```ts
{ id: 'st_overhear', kind: 'look', npc: 'kuroda', label: '改札の陰から様子をうかがう', cost: 10,
  cond: { at: 'station', t: [hm(14, 45), hm(14, 59)], has: ['station_3pm'] },   // 「15時閉鎖」を知った周回だけ
  script: sc(['椎名', '「……地下の件は、今日で最後にしてくれ。」'], fact('kuroda_shiina_talk')) }
```

- `has` / `not`：既知の情報 `flag` / `noFlag`：フラグ（`p:` 始まりは周回をまたいで残る）
- `since` / `past`：「伝えてから◯分後」「前の周回で伝えた」ことを条件にできる（NPCの行動表にも使える）
- 「情報の入手先が存在する」「参照先が実在する」はテストが検証する。

## 攻略ルート（ネタバレ注意）

`tests/walkthrough.test.ts` が、8周でTRUE ENDまで到達できるリファレンスルートになっている。
全ての条件・時間制約がこのテストで検証されるため、シナリオを変更して到達不能になるとテストが落ちる。

## ボリュームについて

現状の収録は、住民12人・場所9か所・イベント75・情報84・推理7種・「伝える」への反応23種。
プレイ時間は未計測だが、リファレンスルート（8周）を初見で探索しながら進めるなら **3〜5時間程度** と見込んでいる。
企画の8〜15時間には、イベント・周回ごとの変化の増量が必要（仕組みはそのまま `src/data/` にデータを足せば拡張できる）。

## itch.io への投稿

1. `npm run pack:itch` で `last-day-itch.zip`（`index.html` が zip 直下、アセットは相対パス）を作る。
2. itch.io で新規プロジェクト → Kind of project: **HTML** → zip をアップロードし「This file will be played in the browser」にチェック。
3. Embed options: 表示サイズは **幅 980 × 高さ 900 程度**（または「Click to launch in fullscreen」）を推奨。「Mobile friendly」は任意。
4. セーブは localStorage（iframe内でも動作。無効な環境でも遊べるが保存されない）。
