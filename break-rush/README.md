# BREAK RUSH — STREET FIGHT

街中で多人数の敵と殴り合う 3D アクション（アーカム／スリーピングドッグス系）。TypeScript + Three.js + Vite。
素材ファイルなし（全部コードで生成）、サーバー不要。

> 過去版: 2D 横スクロール（Phaser）`git show a4dbcfc` ／ 3D サバイバー版・パルクール版は履歴に残っています。

## 遊び方

敵は数人で囲んできますが、**同時に攻撃してくるのは 2〜3 人まで**。攻撃の前には頭上にリングが出ます。

| リング | 意味 | 対処 |
| --- | --- | --- |
| 🔵 青（!） | 通常攻撃 | リングが閉じる瞬間に **カウンター**（右クリック）→ 敵を無傷で倒す。普通のガードは被ダメ 75% カット |
| 🔴 赤（✕） | ガード不能（ブルートの叩きつけ・突進・ボスの大技） | **回避**（Space）だけ |
| 🟡 黄（◎） | 銃撃（ガンマンのレーザー） | 回避する／カウンターで **弾を撃った本人へ打ち返す** |

画面外の敵が攻撃を始めると、画面の縁にその方向の矢印が出ます。

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 / カメラ | WASD / マウス | 左 / 右スティック |
| 攻撃（4連コンボ。近くの敵に自動で踏み込む） | 左クリック | X |
| 強攻撃（ダウンさせる） | E | Y |
| ガード / カウンター（押しっぱなしで構え続け、離すと即解除） | 右クリック | B |
| ジャンプ（2段ジャンプ。離すと低いジャンプ） | Space | A |
| 回避ローリング（無敵つき）／空中ではエアダッシュ（1回のジャンプで2回まで） | Shift / Ctrl | LT |
| 掴んで投げる（他の敵にぶつける・壁にぶつけると追加ダメージ） | F | RB |
| 武器を拾う（バット・パイプ。耐久あり） | Q | LB |
| 銃を撃つ／持っている武器を投げる | G | R3（右スティック押し込み） |
| RUSH（ゲージ満タンで周囲を吹き飛ばす） | R | RT |
| ポーズ | Esc / P | Start |

- 倒れた敵は通常攻撃で追撃できます。ブルートとボスは掴めません。

### スピード＆ジャンプ

- **加速**: 走り続けると約0.5秒で歩きの1.7倍まで加速。FOVが広がり、スピード線と残像が出ます。止まる・被弾でリセット。
- **ジャンプ**: Space（押しっぱなしで高く、すぐ離すと低い）。空中でもう一度押すと2段ジャンプ（宙返り）。滞空中は近接攻撃と銃弾を避けられます。
- **エアダッシュ**: 空中でShiftを押すと一瞬で水平に飛ぶ（2回まで）。そのまま空中コンボへ。
- **フラッシュステップ**: 離れた敵（3.4〜10m）に攻撃ボタンで、一気に飛びかかって斬る。
- **ダイブ攻撃**: 空中で強攻撃 → 急降下、着地の衝撃波で周囲の敵を吹き飛ばす。
- 回避ローリングは距離が伸び、より速くなりました。

### スタイリッシュ戦闘

- **スタイルランク D→C→B→A→S→SS→SSS**: 技を使い分けるほど上がり、同じ技の連打は伸びません。被弾で半減、攻撃を止めると下がります。ランクが高いほど得点倍率UP。
- **ジャストドッジ**: 敵の攻撃が当たる直前ギリギリで回避(Space)すると、約2秒間 **敵だけスローモーション**（こちらは通常速度、与ダメージ+30%）。
- **空中コンボ**: 強攻撃(E)で敵を打ち上げると自分も一緒に飛び上がる → 攻撃連打で空中ラッシュ（空中では近接攻撃を受けない）、Spaceで空中ダッシュ、強攻撃で叩きつけて着地の衝撃波。
- **ガードは軽く**: 軽く押すと約0.34秒の構え（先頭がカウンター判定）。押しっぱなしで構え続け、離せば即解除。構え中も回避へ即キャンセル、少し経てば攻撃へキャンセル。攻撃の硬直も短縮。
- 回避・突進・RUSH には残像が出ます。

### テクニック（できることが増えました）

- **打ち上げ**: 強攻撃(E)で普通の敵を空中に打ち上げ → 通常攻撃を重ねてお手玉（最大6回）→ 落ちる前にもう一度Eで**叩きつけ**（追加ダメージ）。ブルートとボスは打ち上がらず、よろめきます。
- **フィニッシュ**: 倒れていてHPが40%以下の敵のそばで強攻撃(E) → 処刑。HP回復＋スローモーション。
- **ダッシュ攻撃**: 回避ローリングの終わり際（または直後）に攻撃 → 長い踏み込みの蹴り。
- **カウンター連携**: カウンター成功の直後に攻撃 → 次の敵へ飛びかかる追撃。
- **爆発する赤い樽**: 殴る・撃つ・敵を投げつけるで爆発し、周囲の敵（と自分）にダメージ。隣の樽に連鎖します。
- **銃と投擲**: ガンマンが落とすピストル（7発）を拾うとGで射撃。バットやパイプを持っているときのGは投げつけ（大ダメージ）。
- **パーク**: ウェーブをクリアするたびに3つから1つ選ぶ（1/2/3キーかクリック）。与ダメージ+20%、最大HP+30、倒すとHP回復、カウンター受付拡大、爆発強化、投げ強化、受けるダメージ−15% など14種類。ENDLESSでは毎ウェーブ。
- **新しい敵**: **盾持ち**（正面からの攻撃・手裏剣を防ぐ。4回防がせるとガードが崩れる／掴む・背後を取る・爆発・弾き返しは通る）、**アサシン**（背後に回って赤い突進で刺しに来る）。ボスは体力25%以下で激昂。
- コンボを繋ぐと倍率が上がり、被弾すると途切れます。最終スコア = 得点 − 被ダメージ×4。パー（目安）との比でランク S/A/B/C。
- 回避・カウンター・弾き返しは成功するとスローになり、ゲージも溜まります。
- ASSIST をオンにすると敵のダメージが約 45% 減ります。

## ステージ（各 3 ウェーブ）

1. **BACK ALLEY**（雨の夜の路地）— チンピラ／ナイフ
2. **SHOPPING STREET**（夕暮れの商店街）— バット持ち、ガンマン
3. **UNDERPASS**（高架下の駐車場）— 柱の陰から撃つガンマン、ブルート
4. **CENTRAL PLAZA**（昼下がりの広場）— ボス（HP 50% 以下で増援）

加えて **ENDLESS**（敵が増え続ける。ベストスコア保存）。

## 起動

```bash
cd break-rush
npm install
npm run dev           # http://localhost:5173
npm run build         # 型チェック + dist/（itch.io 用）
npm run build:local   # dist-local/index.html 単一HTML（ダブルクリックで起動）
npm test              # Vitest
```

- **itch.io**: `dist/` の中身を ZIP のルートに `index.html` が来るように固めてアップロード（HTML5）。
- **単一HTML**: `dist-local/index.html`（約 0.7MB、上限 20MB）。`file://` で動作。
- 音は最初のクリック後に有効化（autoplay 制限）。効果音は WebAudio 合成。
- 重い端末では自動で軽量モード（ブルーム OFF）に切り替わります。
- 開発用 URL パラメータ: `?debug`（`window.__g`）、`&stage=N`、`&endless`、`&bot`（自動操縦）、`&hifx`（自動軽量化を無効化）。

## 構成

```
src/brawl/   ゲームロジック（Three 非依存）: World（プレイヤー・敵AI・トークン制・弾・投げ・カウンター・打ち上げ・爆発・パーク・ウェーブ）
             data（敵/攻撃の数値）/ perks / stages（ステージ定義・プロップ配置）/ bot（テスト用の自動操縦）
src/game/    Rig（人型キャラクターの骨格とポーズ・アニメーション）/ CityView（街・ライティング・影・雨・カメラ）
             Textures（アスファルト・ファサード・看板などをキャンバスで生成。バンプ付き）。描画: SMAA、ブルーム、ビネット／色調補正／粒子ノイズ、ヒット時の色収差/ Hud / Input / Game / Progress / Fx
tests/       Vitest
```

### テストが保証していること

- 4連コンボ、割り込み（攻撃前の敵を殴ると攻撃がキャンセルされる）、自動踏み込み、ダウン追撃。
- 回避の無敵時間、カウンター成功でノーダメージ、赤攻撃はカウンター不可、同時攻撃数の上限。
- ガンマン: 予告→発射、動けば避けられる、完璧なガードで弾を打ち返して撃った本人を倒す。
- 投げ（他の敵に当たる）、武器の強化と耐久、RUSH、ウェーブ進行、KO 後のウェーブやり直し。
- ガードのキャンセル、ジャストドッジと敵スロー、空中コンボ、スタイルランク。
- 打ち上げ・お手玉・叩きつけ、フィニッシュ、ダッシュ攻撃、カウンター連携、樽の爆発と連鎖、銃と投擲、パーク選択、盾持ち・アサシン、ボス激昂。
- ボット対戦: 何もしないと負ける／防御するボットは序盤を余裕でクリア／殴るだけのボットは多くダメージを受ける。

### 検証できていないこと

手触り（攻撃の間、カメラ、難易度、アニメーションの見栄え）と音は人が遊んで調整する部分です。数値は `src/brawl/data.ts` に集約しています。
