# BREAK RUSH — STREET FIGHT

街中で多人数の敵と殴り合う 3D アクション（アーカム／スリーピングドッグス系）。TypeScript + Three.js + Vite。
素材ファイルなし（全部コードで生成）、サーバー不要。

> 過去版: 2D 横スクロール（Phaser）`git show a4dbcfc` ／ 3D サバイバー版・パルクール版は履歴に残っています。

## 遊び方

敵は数人で囲んできますが、**同時に攻撃してくるのは 2〜3 人まで**。攻撃の前には頭上にリングが出ます。

| リング | 意味 | 対処 |
| --- | --- | --- |
| 🔵 青（!） | 通常攻撃 | リングが閉じる瞬間に **カウンター**（右クリック/Shift）→ 敵を無傷で倒す。普通のガードは被ダメ 75% カット |
| 🔴 赤（✕） | ガード不能（ブルートの叩きつけ・突進・ボスの大技） | **回避**（Space）だけ |
| 🟡 黄（◎） | 銃撃（ガンマンのレーザー） | 回避する／カウンターで **弾を撃った本人へ打ち返す** |

画面外の敵が攻撃を始めると、画面の縁にその方向の矢印が出ます。

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 / カメラ | WASD / マウス | 左 / 右スティック |
| 攻撃（4連コンボ。近くの敵に自動で踏み込む） | 左クリック | X |
| 強攻撃（ダウンさせる） | E | Y |
| カウンター / ガード | 右クリック / Shift | B |
| 回避（無敵つきローリング） | Space | A |
| 掴んで投げる（他の敵にぶつける・壁にぶつけると追加ダメージ） | F | RB |
| 武器を拾う（バット・パイプ。耐久あり） | Q | LB |
| RUSH（ゲージ満タンで周囲を吹き飛ばす） | R | RT |
| ポーズ | Esc / P | Start |

- 倒れた敵は通常攻撃で追撃できます。ブルートとボスは掴めません。
- コンボを繋ぐと倍率が上がり、被弾すると途切れます。最終スコア = 得点 − 被ダメージ×4。パー（目安）との比でランク S/A/B/C。
- 回避・カウンター・弾き返しは成功するとスローになり、ゲージも溜まります。
- ASSIST をオンにすると敵のダメージが約 45% 減ります。

## ステージ（各 3 ウェーブ）

1. **BACK ALLEY**（雨の夜の路地）— チンピラ／ナイフ
2. **SHOPPING STREET**（夕暮れの商店街）— バット持ち、ガンマン
3. **UNDERPASS**（高架下の駐車場）— 柱の陰から撃つガンマン、ブルート
4. **CENTRAL PLAZA**（昼下がりの広場）— ボス（HP 50% 以下で増援）

加えて **ENDLESS**（敵が増え続ける。ベストスコア保存）。

## 起動

```bash
cd break-rush
npm install
npm run dev           # http://localhost:5173
npm run build         # 型チェック + dist/（itch.io 用）
npm run build:local   # dist-local/index.html 単一HTML（ダブルクリックで起動）
npm test              # Vitest
```

- **itch.io**: `dist/` の中身を ZIP のルートに `index.html` が来るように固めてアップロード（HTML5）。
- **単一HTML**: `dist-local/index.html`（約 0.7MB、上限 20MB）。`file://` で動作。
- 音は最初のクリック後に有効化（autoplay 制限）。効果音は WebAudio 合成。
- 重い端末では自動で軽量モード（ブルーム OFF）に切り替わります。
- 開発用 URL パラメータ: `?debug`（`window.__g`）、`&stage=N`、`&endless`、`&bot`（自動操縦）、`&hifx`（自動軽量化を無効化）。

## 構成

```
src/brawl/   ゲームロジック（Three 非依存）: World（プレイヤー・敵AI・トークン制・弾・投げ・カウンター・ウェーブ）
             data（敵/攻撃の数値）/ stages（ステージ定義・プロップ配置）/ bot（テスト用の自動操縦）
src/game/    Rig（人型キャラクターの骨格とポーズ・アニメーション）/ CityView（街・ライティング・影・雨・カメラ）
             Textures（アスファルト・ファサード・看板などをキャンバスで生成）/ Hud / Input / Game / Progress / Fx
tests/       Vitest
```

### テストが保証していること

- 4連コンボ、割り込み（攻撃前の敵を殴ると攻撃がキャンセルされる）、自動踏み込み、ダウン追撃。
- 回避の無敵時間、カウンター成功でノーダメージ、赤攻撃はカウンター不可、同時攻撃数の上限。
- ガンマン: 予告→発射、動けば避けられる、完璧なガードで弾を打ち返して撃った本人を倒す。
- 投げ（他の敵に当たる）、武器の強化と耐久、RUSH、ウェーブ進行、KO 後のウェーブやり直し。
- ボット対戦: 何もしないと負ける／防御するボットは序盤を余裕でクリア／殴るだけのボットは明確に多くダメージを受ける。

### 検証できていないこと

手触り（攻撃の間、カメラ、難易度、アニメーションの見栄え）と音は人が遊んで調整する部分です。数値は `src/brawl/data.ts` に集約しています。
