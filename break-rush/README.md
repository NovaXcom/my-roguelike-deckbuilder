# BREAK RUSH — 3D パルクール × 一撃アクション

TypeScript + Three.js + Vite。素材ファイルなし（全部コードで生成）、サーバー不要。

> 過去版: 2D 横スクロール（Phaser）`git show a4dbcfc` ／ 3D サバイバー版は 1 つ前のコミット。

**ミラーズエッジ × ゴーストランナー**風。止まらずに走り、跳び、壁を走り、弾を弾き返し、一撃で斬る。
やられたら一瞬でチェックポイントから再開。タイムアタックでランク（S/A/B/C）。

## 操作

| 操作 | キーボード＋マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD | 左スティック |
| 視点 | マウス（クリックでキャプチャ）/ 矢印キー | 右スティック |
| ジャンプ（長押しで高く） | Space | A |
| エアダッシュ | Shift | RB |
| スライディング | Ctrl / C | B |
| 斬る＋ロックオン突進 | 左クリック | X / RT |
| **弾き返し**（飛んでくる弾を撃った敵へ反射） | 右クリック | LT / LB |
| 手裏剣（遠距離。3発、キルで回復） | E / ホイールクリック | LB |
| フォーカス（スローモー） | Q / F | Y |
| チェックポイントからやり直し | R | — |
| ポーズ | Esc / P | Start |

- **壁走り**: オレンジの縁取りの壁に空中で走り込むと壁を走れる（約1.9秒）。ジャンプで壁から跳ぶ。
- **一撃**: 敵の弾・突進・レーザー・落下で即死。ただし敵も一撃。タイトルの **ASSIST** をオンにすると 3 回まで耐えられる。
- 敵を倒すと突進とダッシュが回復、フォーカスゲージも少し溜まる。
- ステージは 5 つ＋毎日同じコースの **DAILY RUN**（日付シード）。クリアで次が解放。それぞれ見た目と出てくる仕掛けが違う:
  1. ROOFTOPS（昼のビル群）/ 2. IRONWORKS（工場・ジャンプパッド）/ 3. OVERGROWN（遺跡・崩れる足場・壁走り）/ 4. CANYON RUN（夕焼けの渓谷・長距離ダッシュ）/ 5. NEON ZERO（夜のネオン）。
- 仕掛け: **ジャンプパッド**（緑）、**崩れる足場**（乗って約0.5秒で落ちる）、**アリーナ**（敵を全滅させるまで出口が閉じる）、低いレーザー（跳ぶ）と高いレーザー（滑る）。
- 敵: **ガンナー**（赤いレーザーで狙ってから発射。弾は弾き返せる）/ **チャージャー**（溜めてから突進）/ **ドローン**（空中から撃つ。手裏剣向き）/ **シールド兵**（正面からの斬撃・手裏剣は防ぐ。回り込む・飛び越えて背後から斬る、弾き返した弾は通る）。

## 起動

```bash
cd break-rush
npm install
npm run dev           # http://localhost:5173
npm run build         # 型チェック + dist/（itch.io 用）
npm run build:local   # dist-local/index.html 単一HTML（ダブルクリックで起動）
npm test              # Vitest
```

- **itch.io**: `dist/` の中身を ZIP のルートに `index.html` が来るように固めてアップロード（HTML5）。
- **単一HTML**: `dist-local/index.html`（20MB 上限に対し約 0.7MB）。`file://` で動作。
- 音は最初のクリックの後に有効化（ブラウザの autoplay 制限）。効果音は WebAudio 合成で、音声ファイル不要。
- 重い端末では自動で軽量モード（ブルーム OFF）に切り替わります。
- URL パラメータ（開発用）: `?debug`（`window.__g`）、`&stage=N`、`&auto`（コース上の想定ルートを自動操縦）、`&hifx`（自動軽量化を無効化）。

## 構成

```
src/physics/   移動の物理（Three 非依存）: Controller（コヨーテ/先行入力/可変ジャンプ/スライド/エアダッシュ/壁走り）
src/level/     コース生成: 部品（gap・dashgap・climb・slide・wallrun・pillars・laser・pad・crumble・arena…）をシードで連結
src/game/      Combat（敵AI・弾・弾き返し・斬撃, 純ロジック）/ AutoPilot / Progress（ランク・セーブ）/ Rng
               SceneView（Three.js 描画）/ Theme・Textures（ステージごとの見た目）/ Hud（DOM）/ Input（KB+マウス+パッド）/ Game（ループ）
tests/         Vitest: 物理・コース生成・戦闘・進行
```

### テストが保証していること

- ジャンプ高/距離、コヨーテ/先行入力、スライドで低い天井を抜ける、エアダッシュで届く距離、壁走りでしか渡れない谷を渡れる、壁走りの時間制限。
- 生成された全ステージ（5段階×各40シード）が、想定ルートを辿る自動操縦で**必ずクリアできる**（物理定数から部品を作っているため）。
- 敵: 視線が遮られたら撃たない、弾き返しで撃った敵が死ぬ、チェックポイントでの敵復活、など。

### 検証できていないこと

手触り（慣性・カメラ・難易度）と音は人が遊んで調整する部分です。物理定数は `src/physics/config.ts` に集約してあります。
